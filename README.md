# 提瓦特档案 · 原神资料站

一个纯前端（HTML + CSS + JavaScript，零依赖、零构建）的《原神》资料页面，展示：

- 🎬 **实机影像馆**：官方版本 PV、角色演示、剧情 CG、实机演示、音乐会等，支持 Bilibili / YouTube 双源内嵌播放
- 🕰 **版本里程碑时间线**：从 1.0 公测到当前最新版本的每一次大版本更新
- 🏆 **获奖记录**：TGA、金摇杆、App Store / Google Play 年度游戏、PS 合作伙伴奖等获奖与提名
- 📊 **数据里程碑**：平台上线、玩家规模、流水与重要活动节点
- 🗺 **提瓦特七国**：七神、七元素与地区速览
- 📁 **我的档案**：收藏、评分、笔记、观看历史、自定义影像，全部写入浏览器 `localStorage`

## 运行方式

**方式一（最简单）**：直接双击 `index.html`，用浏览器打开即可浏览资料；播放内嵌视频时需要联网。

**方式二（推荐，保证本地存储可用）**：双击 `启动本地服务器.bat`，脚本会自动检测 Python / Node.js 并启动静态服务器、打开浏览器：

```powershell
# 也可以手动执行
python -m http.server 8080        # 或：npx --yes serve .
# 然后访问 http://localhost:8080/index.html
```

> 为什么推荐方式二：部分浏览器（尤其 Chrome）在 `file://` 协议下会禁用 `localStorage`，此时收藏与笔记无法持久化。
> 页面检测到这种情况会自动在顶部显示橙色提示条，并说明解决办法；改用 `http://localhost` 访问后即可正常保存。

## 本地存储说明

- 存储键：`gi_archive_v1`（单个 JSON，带版本号，便于后续迁移）
- 会持久化的内容：主题偏好、收藏的影像与奖项、评分、影像笔记、独立笔记、已回顾版本、最近观看、自定义影像、筛选状态、访问统计
- 页面右下角「我的档案」区域可以查看占用空间、首次/最近访问时间
- 支持 **导出 JSON 备份** 与 **导入备份**，换浏览器或换电脑时可以迁移数据
- 「清空本地数据」会重置收藏与笔记，但保留访问统计

## 自定义影像

在「实机影像馆」底部展开「＋ 添加自定义影像」，粘贴 Bilibili 链接 / BV 号 或 YouTube 链接 / 11 位视频 ID，即可加入自己的实机录像、抽卡记录等，条目同样保存在本地存储中。

## 资料来源与准确性

- **版本**：原神 WIKI 版本历史、HoYoverse 官方版本更新说明、Gematsu、電撃オンライン（52 个版本逐条核对日期，更新节奏为 6 周一次）
- **影像**：每条 BV 号都通过 B 站官方接口 `api.bilibili.com/x/web-interface/view` 核实过标题、发布日期与 UP 主，**仅收录官方「原神」账号（mid=401742377）稿件**；YouTube 仅收录能从官方新闻稿中确认的 ID，无法核实的留空
- **奖项**：PlayStation 官方历届获奖页、Apple Design Award 报道、GameLook、IT之家等；无法核实的奖项（如部分票选类奖项）一律不写入，避免出错
- **数字**：仅使用有明确报道出处的数据（如移动端流水与下载量引自 17173 报道），未做任何估算

## 自检脚本

```powershell
node tests/modal-close.test.js   # 弹层「打开 → 遮罩 / ✕ / ESC 关闭」链路测试（14 项断言）
```

`tests/browser-modal-check.html` 是真实浏览器端到端检测页：把它放在本地服务器下打开，
它会在同源 iframe 中加载首页，用真实事件依次验证「加载即不可见 → 点击打开 → 遮罩关闭 →
✕ 关闭 → ESC 关闭」，并核对各板块渲染数量（当前 19 项全部通过）。

```powershell
# 可选：通过 GitHub REST API 把本地文件作为一次提交上传（适合 git 协议不通、仅 api.github.com 可用的网络）
$env:GH_TOKEN = '<classic token，勾选 public_repo>'
pwsh -File tools/upload-to-github.ps1 -EnablePages
```

> ⚠️ 维护提示：作者样式中的 `display` 会覆盖浏览器对 `[hidden]` 属性的默认 `display:none`。
> 因此 `css/styles.css` 第 43 行保留了 `[hidden]{display:none!important}`。
> 一旦删除，弹层被 JS 设为 `hidden` 后仍会显示（表现为「弹窗关不掉」），收藏区的「原站观看」按钮也会失效。
